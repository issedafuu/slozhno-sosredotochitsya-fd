# Сложно сосредоточиться

Учебный проект курса «Фронтенд-разработчик» от Яндекс.Практикума.  
Одностраничный сайт, который объясняет, почему нам трудно концентрироваться и что с этим делать.

## О проекте

Вёрстка выполнена по предоставленному макету для трёх основных разрешений: 375px, 768px и 1024px.  
Реализованы две цветовые схемы — светлая и тёмная. Переключение происходит либо автоматически, опираясь на системные настройки пользователя, либо вручную с помощью кнопок на странице.

При создании использовались:

- Методология Mobile First: сначала писалась разметка и стили для мобильных экранов, затем добавлялась адаптация для планшетов и десктопов.
- CSS Grid для построения сеток секций и галереи — это позволило менять расположение элементов без лишних обёрток.
- Функция `clamp()` для плавного изменения размера заголовков.
- CSS-переменные для управления цветами, фонами и шрифтами — они переопределяются в зависимости от активной темы.
- JavaScript-скрипт (предоставлен курсом), который управляет классами темы на элементе `<html>`.

## Возможности

- Адаптивная вёрстка без горизонтальной прокрутки на любых экранах от 375px.
- Светлая и тёмная темы, выбор сохраняется после перезагрузки.
- Кнопки переключения: «День», «Авто», «Неон» — активная кнопка подсвечивается.
- Галерея с «ленивой» загрузкой изображений (`loading="lazy"`).
- Элементы интерфейса имеют состояния при наведении и фокусе.
- Декоративные уголки и метка REC (только в тёмной теме).

## Технологии

- HTML5 (семантические теги, доступность)
- CSS3 (кастомные свойства, медиазапросы, псевдоэлементы, гриды)
- JavaScript (управление темами — код из стартового шаблона)

## Как запустить

Достаточно открыть файл `index.html` в любом современном браузере.  
Или задеплоить на GitHub Pages (ссылка на свой репозиторий).

## Что внутри

- `index.html` — вся разметка страницы
- `styles/`
  - `globals.css` — сбросы и базовые стили
  - `variables.css` — переменные для основной (светлой) темы
  - `style.css` — основные стили и медиазапросы
  - `dark.css` — переопределение переменных для тёмной темы
  - `light.css` — принудительная светлая тема
- `fonts/` — шрифты IBM Plex Mono
- `images/` — изображения, фавиконки
- `scripts/script.js` — логика переключения тем

## Примечания

- Проект выполнен в учебных целях, не является коммерческим продуктом.
- Вёрстка проверена на трёх контрольных разрешениях и в промежуточных состояниях.
- Все цвета и фоны управляются через переменные, что упрощает смену тем.
